# Sponsor logos

Drop logo files here, then reference them from `our-sponsors.md`:

    <img src="/assets/sponsors/<file>" alt="<Sponsor name>" loading="lazy">

Prefer SVG. Otherwise PNG with a transparent background, at least 400px wide.
Keep each file under about 100KB so the page stays fast.

**This repo is public.** Nothing about who has paid, what they paid, or why anyone is
or is not listed belongs in this repo, including in comments and commit messages.
